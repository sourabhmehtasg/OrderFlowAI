# 🚀 OrderFlowAI

**Turn messy order communications into clean, structured data — instantly.**

---

## 🧠 The Problem

Modern businesses receive orders through:

- Emails
- PDFs
- Text Files
- WhatsApp messages
- Unstructured text

This leads to:

- ❌ Manual data entry  
- ❌ Human errors  
- ❌ Delayed processing  
- ❌ Operational inefficiencies  

---

## ⚡ The Solution

OrderFlowAI intelligently converts unstructured order inputs into structured, ready-to-use data.

---

## 🔄 Before → After

| Before (Unstructured Input) | After (Structured Output) |
|---------------------------|---------------------------|
| "Hi, I need 200 units of blue cotton shirts size M, deliver by next Friday to Berlin." | `{ "product": "cotton shirt", "color": "blue", "size": "M", "quantity": 200, "delivery_location": "Berlin", "delivery_date": "Next Friday" }` |
| "Please send 50 black jackets and 30 white ones to NYC warehouse." | `{ "items": [ { "product": "jacket", "color": "black", "quantity": 50 }, { "product": "jacket", "color": "white", "quantity": 30 } ], "location": "NYC warehouse" }` |
